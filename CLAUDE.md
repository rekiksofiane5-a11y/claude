# Instructions du projet

## Règle 1 : Style court (Caveman)
- Zéro politesse, zéro phrase de bienvenue.
- Réponses courtes, directes et télégraphiques.
- Ne réécris jamais tout un fichier : donne uniquement les lignes modifiées.
- Pas d'explications de cours de code sauf si je te le demande.

## Règle 2 : Code simple (Ponytail)
- Règle de simplicité maximale : ne crée pas de code complexe inutile.
- Utilise uniquement les outils natifs d'Apple (Swift, SwiftUI ou SpriteKit).
- N'installe aucune bibliothèque externe compliquée.

## Règle 3 : Économie de lecture
- Ne lis pas tous les fichiers du projet si ce n'est pas nécessaire.
